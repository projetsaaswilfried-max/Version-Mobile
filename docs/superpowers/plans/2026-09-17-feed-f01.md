# Fil F01 lecture seule Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remplacer le placeholder de l'onglet Fil par la liste officielle Supabase (F01 lecture seule).

**Architecture:** Feature `feed/` 3 couches. `home/FeedTabPage` garde AppBar + cloche ; le body héberge le fil. `GetFeed` pagine 20, `post_type = OFFICIAL` uniquement.

**Tech Stack:** Flutter, Riverpod Notifier, Equatable, supabase_flutter, Result/Failure, tokens `core/theme`.

**Spec :** `docs/superpowers/specs/2026-09-17-feed-f01-design.md`

## Global Constraints

- Feature-first, flèches vers l'intérieur ; domain Dart pur
- Tokens only (`context.colors` / `AppSpacing` / `AppRadius`) : jamais de couleur/taille en dur
- `PERSONAL` jamais dans ce fil
- Actions carte visibles, `IgnorePointer` (pas de like/share/save/F02)
- Pas de `record_post_view`, Realtime, popup Premium, lecteur vidéo
- Chips : Tout le fil, Enseignements, Témoignages, Atelier/Mariage, Conseils & Préparation, Pensées & Citations, Plus (Annonce / Verset / Nouveauté)
- Page size 20, scroll infini + pull-to-refresh
- Issue #9 non fermée
- Conventional Commits FR, pas de Co-Authored-By, pas de tirets cadratins
- `flutter analyze` propre + `flutter test` verts
