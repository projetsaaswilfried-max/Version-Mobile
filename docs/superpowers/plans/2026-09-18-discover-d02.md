**Interfaces:**
- Consumes: callbacks only (pas de Riverpod dans le widget)
- Produces:

```dart
class DiscoverSearchBar extends StatelessWidget {
  const DiscoverSearchBar({
    super.key,
    required this.unlocked,
    required this.onLockedTap,
    required this.onUnlockedSearch,
    required this.onUnlockedFilters,
  });

  final bool unlocked;
  final VoidCallback onLockedTap;
  final VoidCallback onUnlockedSearch;
  final VoidCallback onUnlockedFilters;
}
```

UI :
- `Row` : champ élargi + bouton Filtres (icône `Icons.tune` ou `Icons.filter_list` + texte `Filtres`)
- Champ : `TextField` dense, tokens ; si `!unlocked` → `readOnly: true`, `enableInteractiveSelection: false`, hint `Passe Premium pour rechercher`, `onTap: onLockedTap`
- Si `unlocked` → hint `Rechercher un profil`, `onSubmitted: (_) => onUnlockedSearch()`, éventuellement suffix loupe qui appelle `onUnlockedSearch`
- Bouton Filtres : `!unlocked` → `onLockedTap` ; sinon `onUnlockedFilters`
- Padding horizontal `AppSpacing.lg`, vertical `AppSpacing.sm` ; pas de couleur en dur
